# Γρήγορη Εκκίνηση - Σύστημα Διαχείρισης Σπουδαστών

Οι τελικοί χρήστες εγκαθιστούν την εφαρμογή με τον εγκαταστάτη των Windows
`SMS_Installer_<έκδοση>.exe` από την
[τελευταία έκδοση](https://github.com/bs1gr/AUT_MIEEK_SMS/releases/latest) στο GitHub του
έργου (δείτε το [README.md](../../README.md)). Αυτή η σελίδα είναι για την εκκίνηση της
εφαρμογής από τα αρχεία του έργου.

**Διαβάστηκε με βάση τα σκριπτ:** 18 Νοεμβρίου 2026, `main` μετά την v1.18.73 (`DOCKER.ps1`,
`NATIVE.ps1`). Οι εντολές δεν εκτελέστηκαν για αυτόν τον έλεγχο.

> Χρησιμοποιήστε: **DOCKER.ps1** (Docker) ή **NATIVE.ps1** (λειτουργία ανάπτυξης).
> Τα παλιά RUN.ps1 / SMS.ps1 / INSTALL.ps1 / SMART_SETUP.ps1 δεν υπάρχουν πια.

## Πού βρίσκονται τα σκριπτ

Στον φάκελο του έργου (αντίγραφο του αποθετηρίου, ή το ZIP του αφού αποσυμπιεστεί) τα δύο
σκριπτ βρίσκονται στο `infra\scripts\dev\`. Στον επάνω φάκελο δεν υπάρχει ούτε `DOCKER.ps1`
ούτε `NATIVE.ps1`. Ο εγκαταστάτης τα αντιγράφει στον φάκελο εγκατάστασης: σε ένα
εγκατεστημένο αντίγραφο τρέχετε `.\DOCKER.ps1` και `.\NATIVE.ps1` εκεί. Οι εντολές παρακάτω
είναι για τον φάκελο του έργου· ανοίξτε το PowerShell μέσα σε αυτόν.

## Σε 3 Βήματα

### Βήμα 1: Προαπαιτούμενα (μόνο την πρώτη φορά)

- **Λειτουργία Docker:** Docker Desktop (<https://www.docker.com/products/docker-desktop>).
  Python και Node.js δεν χρειάζονται στον υπολογιστή: η εικόνα χτίζεται μέσα στο Docker.
- **Λειτουργία Native:** Python 3.13 ή νεότερο (<https://www.python.org/downloads/>) και
  Node.js 20.19 ή νεότερο, ή 22.12 ή νεότερο (<https://nodejs.org/>).

### Βήμα 2: Αρχική εγκατάσταση (μόνο την πρώτη φορά)

```powershell
# Αντίγραφο του αποθετηρίου
git clone https://github.com/bs1gr/AUT_MIEEK_SMS.git
cd AUT_MIEEK_SMS

# Επιλογή 1 (Docker, για παραγωγή):
.\infra\scripts\dev\DOCKER.ps1 -Install

# Επιλογή 2 (Native, για ανάπτυξη):
.\infra\scripts\dev\NATIVE.ps1 -Setup
```

Όταν το σκριπτ δημιουργεί το αρχείο ρυθμίσεων (`config\.env` στο Docker,
`src\backend\.env` στο Native), εκτυπώνει το email και τον κωδικό του διαχειριστή που
παρήγαγε το ίδιο. Συνδεθείτε με αυτά στην πρώτη σελίδα της εφαρμογής. Η πρώτη σύνδεση ζητά
νέο κωδικό, και μέχρι να αλλάξει δεν ανοίγει τίποτα άλλο. Αν το αρχείο υπήρχε ήδη, ο
διαχειριστής είναι αυτός που ορίζουν τα `DEFAULT_ADMIN_EMAIL` και `DEFAULT_ADMIN_PASSWORD`
μέσα σε αυτό.

### Βήμα 3: Καθημερινή χρήση

```powershell
# Docker (ένα κοντέινερ)
.\infra\scripts\dev\DOCKER.ps1 -Start     # Εκκίνηση
.\infra\scripts\dev\DOCKER.ps1 -Update    # Ανακατασκευή με αντίγραφο ασφαλείας
.\infra\scripts\dev\DOCKER.ps1 -Stop      # Διακοπή

# Native (ξεχωριστό backend και frontend)
.\infra\scripts\dev\NATIVE.ps1 -Start
.\infra\scripts\dev\NATIVE.ps1 -Stop
```

## Βασική Αντιμετώπιση Προβλημάτων

### Η θύρα 8000 είναι κατειλημμένη (Native API)

```powershell
# Βρείτε ποια διεργασία χρησιμοποιεί τη θύρα
netstat -ano | findstr :8000
```

Το `NATIVE.ps1` χρησιμοποιεί μόνο τη θύρα 8000 για το backend. Τρέξτε
`.\infra\scripts\dev\NATIVE.ps1 -Stop` και ξεκινήστε ξανά, ή ελευθερώστε τη θύρα 8000
χειροκίνητα.

### Λείπουν Python modules (Native)

Τρέξτε ξανά `.\infra\scripts\dev\NATIVE.ps1 -Setup`. Εγκαθιστά τα πακέτα Python στο
virtual environment `src\backend\.venv`. Χειροκίνητα:

```powershell
cd src\backend
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Το frontend δεν φορτώνει (Native)

Τρέξτε ξανά `.\infra\scripts\dev\NATIVE.ps1 -Setup`, που εγκαθιστά τα πακέτα Node.js.
Χειροκίνητα:

```powershell
cd src\frontend
npm install
npm run dev
```
