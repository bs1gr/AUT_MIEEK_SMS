# Themes: summary

**Checked against the application:** 18 November 2026, `main` after v1.18.73.

The application has eight themes. You choose one under Utils > **Settings**, in the box
**Appearance Themes**, with the button **Theme**. The pages change at once, and the choice is
remembered on the device, not in your account.

The earlier text of this note described six themes chosen in the Control Panel, with mock-ups
of a header and its Theme button. That is not how the application works today. The earlier
text is in the repository's history. The steps, the Greek lines and the part for developers
are in [THEME_GUIDE.md](THEME_GUIDE.md).

| English | Greek | What the page says about it |
|---|---|---|
| **Default** | **Προεπιλογή** | Balanced light/dark theme |
| **Glassmorphism** | **Glassmorphism** | Frosted glass with blur effects |
| **Neumorphism** | **Neumorphism** | Soft 3D depth with shadows |
| **Gradient** | **Gradient** | Vibrant gradients with glass accents |
| **Modern Dark** | **Σύγχρονο Σκοτεινό** | High-contrast night mode |
| **Light Professional** | **Φωτεινό Επαγγελματικό** | Clean minimal light mode |
| **ΜΙΕΕΚ** | **ΜΙΕΕΚ** | Professional admin interface with green accent |
| **ΜΙΕΕΚ Dark** | **ΜΙΕΕΚ Σκοτεινό** | Dark professional interface with vivid white text |

Two of the eight are dark: **Modern Dark** and **ΜΙΕΕΚ Dark**.
